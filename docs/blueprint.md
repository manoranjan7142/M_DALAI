# **App Name**: Manoranjan Dalai: Neon Ascent

## Core Features:

- Hero Section: Animated intro text, role switcher with typing effect, 3D or parallax background, and CTAs.
- About Me Story: Timeline-based journey animation highlighting education and experience, animated counters for key metrics.
- Skills Showcase: Interactive glowing tech cards for MERN stack, expandable tools & experience on hover, skill radar or animated progress rings.
- Project Showcase: SaaS-style project cards with category filters, live preview/GitHub hover options, and modal popups for detailed project info.
- Experience Timeline: Animated vertical timeline featuring past roles, with smooth scroll reveal animations.
- Contact Form (UI): Glassmorphism contact form with floating labels and neon hover submit button.
- Command Palette Navigation: A command palette (Ctrl+K) allows users to quickly navigate to any section of the portfolio.

## Style Guidelines:

- Primary color: Neon Teal (#00FFD1) for a futuristic and vibrant feel.
- Secondary color: Electric Violet (#7F00FF) as a complementary accent.
- Highlight color: Cyber Pink (#FF2E93) for interactive elements and glows.
- Base color: Deep Space Black (#000000) to enhance neon colors.
- Body and headline font: 'Space Grotesk' sans-serif, suitable for both headlines and shorter lengths of body text, providing a techy, scientific feel.
- Use glowing, minimalist icons for navigation and actions, aligned with the neon aesthetic.
- Glassmorphism cards with neon glow borders and animated gradient backgrounds, focusing on a dashboard-like structure.
- Smooth page transitions, magnetic hover effects, and subtle animations to enhance user experience.
